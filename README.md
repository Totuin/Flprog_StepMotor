# Flprog_StepMotor 1.0.1

Библиотека управления шаговыми двигателями в FLProg.

## Типы и режимы

- `FLProgPulDirStepMotor` — внешний драйвер STEP/PUL + DIR.
- `FLProgFourWireControlledStepMotor` — прямое управление четырьмя обмотками, полный/полушаг.
- Режимы: остановка, непрерывное вращение, позиционирование, движение по заданному количеству шагов, поиск нуля.

## Требования к вызовам

- `tick()` вызывается **периодическим аппаратным таймером**; значение `tickPeriod(...)` должно совпадать с реальным периодом прерывания в микросекундах.
- `pool()` вызывается из основного цикла, поддерживает разгон, режимы и датчик нуля.
- `tickPeriod(0)` игнорируется. `startAccelerationSpeed(0)` нормализуется до 1 шага/с.
- `pulseTime()` для STEP/DIR ограничено минимумом 10 мкс; длительность округляется вверх по шагу таймера.
- Скорость задаётся в шагах/с, но при высокой частоте ограничивается периодом внешнего таймера и необходимостью выдержать LOW между импульсами.
- `goThroughSteps(N)` добавляет N шагов к активной команде; счётчик дополнительных шагов насыщается при переполнении.

## Важные ограничения

1. Поля положения/скорости могут обновляться из прерывания. На AVR 8 бит чтение 16/32-битных значений из loop() без защиты прерываний может давать неконсистентные значения. Простое `volatile` не гарантирует атомарности. Синхронизацию необходимо продумать в вызывающем коде.
2. Для исходной версии и 1.0.1 **не выполнялось реальное испытание мотора на оборудовании**; необходима проверка полярности сигналов и скорости.
3. Точность времени задаётся разрешением внешнего таймера; высокий `maxSpeed` может быть физически недостижим.
4. Счётчик `currentStep` насыщается на `INT32_MIN`/`INT32_MAX`, а сам двигатель продолжает вращаться.
5. Историческое название `currenrSpeed()` сохранено для совместимости; публичный API не переименован.
